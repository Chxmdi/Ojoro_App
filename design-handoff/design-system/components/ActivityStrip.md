# ActivityStrip

Compact one-line activity: time in display, name and place in UI type, status at the end.

**Properties** `activity`, `time`, `place`, `count`, `capacity`, `status` (`forming` · `confirmed` · `live` · `full`), `href`.
**Composition** strips stack, separated by `line` hairlines — no cards.
**Accessibility** whole row is one link, `size-touch` tall.
