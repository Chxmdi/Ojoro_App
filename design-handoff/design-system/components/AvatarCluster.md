# AvatarCluster

People assembling: overlapping avatars, a +N count and optional open slots.

**Properties** `people`, `total`, `max` (shown before +N), `open` (dashed empty Os), `size`.
**Motion** Gather — a newly joined person (`isNew`) flies in with `dur-gather` / `ease-gather`; the cluster gets denser.
**Accessibility** group label "6 people in, 2 open".
