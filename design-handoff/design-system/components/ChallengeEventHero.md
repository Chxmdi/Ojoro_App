# ChallengeEventHero

The top of a Challenge Event page; its situation escalates with `stage`.

**Variants (`stage`)** `accepted`/`days` → forming (poster + countdown) · `today` → confirmed (TODAY.) · `soon` → confirmed (ALMOST TIME.) · `live` → live (progress takes over) · `complete` → after (CHIMDI WINS.).
**Properties** `a`, `b` (`{name, progress}`), `discipline`, `stage`, `when`, `countdown`, `winner`, `result`.
**Below it** PredictionBar, CrowdSupport, then the HypePost feed.
**Haptic** Medium impact when both competitors check in; Success when the result is verified.
