# Comment

A comment in a thread: small avatar, name, time, body, and text actions.

**Properties** `author`, `body`, `time`, `badge` (COMPETITOR, HOST), `respect`, `respected`, `replies`, `reply` (indented one level — never deeper).
**Rules** text actions in `label-sm`; RESPECT is the only like.
**Accessibility** actions have 44px hit areas extended beyond their visible text.
