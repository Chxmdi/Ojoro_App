# CrowdSupport

THE CROWD — how many people back each competitor, with a BACK action.

**Properties** `a`/`b` `{name, count}`, `backing`, `onBack(side)`.
**States** not backing (two secondary buttons) · backing one (that button primary, reads BACKING).
**Haptic** none — backing is light social action. **Analytics** `crowd_backed{side}`.
