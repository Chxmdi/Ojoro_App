# DisplayText

Uppercase display type in the condensed face — the emotional layer of every screen.

**Properties** `size` (`hero` · `xl` · `lg` · `md` · `sm` · `xs`), `as` (heading level), `muted`.
**Rules** at most one `hero` per screen; pair every display headline with a `body` line in UI type underneath (the editorial block); never below `xs` (24px); facts end with a period (TONIGHT.).
**Accessibility** use a real heading element via `as`; dynamic type scales display up to 1.3× then wraps — never truncate.
