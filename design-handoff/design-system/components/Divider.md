# Divider

Separation between editorial blocks: a hairline, a strong rule, or the Mark.

**Variants** `hair` (`line`, default between strips) · `strong` (`line-strong`, between sections) · `mark` (a skewed `border-poster` bar — competition and VS only).
**Properties** `kind`, `label` (an overline set into the rule: TONIGHT, THIS WEEK, VS).
**Rules** prefer a ground change or space to a divider; never stack two.
