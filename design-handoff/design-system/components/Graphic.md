# Graphic

The brand's graphic language as inline SVG in `currentColor`: the O, the Trail, the Mark and scribbles.

**Properties** `kind` (`o` · `trail` · `mark` · `scribble-circle` · `underline` · `arrow` · `crown`), `size`, `strokeWidth`, `label` (only if meaningful; otherwise decorative and hidden).
**Rules** scribbles sparingly — one per screen; sports notebook, never childish.
