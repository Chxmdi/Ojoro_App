# HypePost

A post inside a Challenge Event feed; its kind is named in words, not colour.

**Variants (`kind`)** `system` (inverse strip, display text — OJORO updates) · `competitor` (larger body, signal badge) · `evidence` (training stats block) · `supporter` (small avatar, neutral badge).
**Properties** `kind`, `author`, `body`, `time`, `side`, `stats`.
