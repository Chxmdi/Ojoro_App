# Icon

Ojoro's own line icons: a 24px grid, 2px stroke, square caps and mitred joins, drawn in `currentColor`.

**Properties** `name` (close · back · forward · plus · more · share · bell · chat · pin · clock · check · alert · offline · lights · search · people), `size` (default 24; 16 and 20 inside text), `strokeWidth`, `label` (only when the icon stands alone and means something).
**Rules** the icon is never the only carrier of meaning — pair it with a word, or give its button an `aria-label`. No filled icons, no emoji, no third-party icon fonts beside these. Need a new glyph? Draw it on the same grid and stroke.
