# Image

Documentary photography in a fixed ratio, with an optional black scrim and display type over it.

**Properties** `src`, `alt` (required — describe what happened, not "photo"), `ratio` (`4:5` feed default · `1:1` · `16:9` · `3:4`), `caption`, `credit`, children (overlay — renders on an `opacity-scrim` black scrim in the live situation so type stays white).
**States** loading/missing: a sunk frame with the O and the alt text; never a broken image.
**Rules** candid, local, imperfect — no stock athletes smiling at the camera. Credit the person who shot it.
