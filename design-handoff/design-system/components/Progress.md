# Progress

Segmented count — one segment per spot, so 6 / 8 can be counted without colour.

**Properties** `value`, `max` (default 8), `label`.
**Rules** filled segments are `signal`, empty are `track`, separated by `space-1` gaps. Use for plan capacity and challenge progress, never for XP.
**Accessibility** `role=progressbar` with value/min/max and a spoken label ("6 of 8 committed").
