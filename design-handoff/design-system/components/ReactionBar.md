# ReactionBar

Typed reactions instead of emoji — Ojoro's crowd noise.

**Properties** `reactions` (`{label, count, mine}`), `onReact(label)`.
**Rules** the vocabulary is fixed: LET'S GO, RESPECT, HOLD THAT, RUN IT BACK. Your reaction fills with `signal`; counts use tabular figures.
**Motion** Commit compress on tap. **Haptic** none.
**Accessibility** each is a toggle button announcing label, count and whether you reacted.
