# Rematch

The request to go again after a result — the bridge from After back to a new Call-Out.

**Properties** `requester`, `opponent`, `discipline`, `lastResult`, `note`, `onAccept`, `onDecline`. (`from` and `to` still work but are deprecated: an `x-import` reads `from` as a file to load, so the component can't be mounted on a Claude Design canvas with it.)
**Rules** the after situation, with the Mark; REMATCH? is set in `display-lg` so it fits a phone. Accepting creates a new Call-Out marked REMATCH and links it to the Rivalry. NOT YET is never shamed.
**Haptic** Heavy impact on accept. **Analytics** `rematch_requested`, `rematch_accepted`.
