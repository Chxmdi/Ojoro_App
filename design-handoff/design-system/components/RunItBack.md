# RunItBack

The after-game prompt to repeat a good session with the same people.

**Properties** `activity`, `crew`, `lastDate`, `count`, `suggested`, `people`, `onRun`, `onChange`.
**Rules** the after situation (stone); appears once, the morning after. RUN IT BACK creates a plan pre-filled with the same crew invited.
**Haptic** Light impact on RUN IT BACK. **Analytics** `run_it_back_shown`, `run_it_back_tapped`.
