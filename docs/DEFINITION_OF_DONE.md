# Definition of Done

A story is done when:
- acceptance criteria are verified;
- code is merged and deployed to the required environment;
- automated test evidence is present;
- telemetry/logging/tracing is implemented;
- accessibility is checked for changed critical flows;
- security/privacy/safety checks are complete;
- data migration and rollback are verified if applicable;
- support/runbook/docs are updated;
- feature flag and rollback behavior are validated where relevant;
- no undocumented manual database manipulation is required.
