# PRD Traceability

The repository delivery hierarchy mirrors the Ojoro v2.0 PRD:
- 12 release milestones
- 16 epics
- 64 implementation stories
- 256 implementation tasks

Each story contains four implementation tasks:
1. domain/schema/contracts;
2. backend/domain behavior;
3. client/user experience;
4. automated verification, telemetry and safety/privacy evidence.
