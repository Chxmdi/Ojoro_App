# Product Delivery Structure

## Milestones
D0 Design Foundation → M0 Foundation → M1 Identity → M2 Crews & Intent → M3 Activity Core → M4 Ojoro Now → M5 Social Layer → M6 Challenges → M7 Clans & Hosts → M8 Places & Progress → M9 AI / Trust / Monetization → M10 Connected Movement Beta → M11 City Scale / GA

## Hierarchy
Milestone → Epic issue → Story issue → four implementation tasks inside each story.

This preserves the complete **16-epic / 64-story / 256-task** PRD structure without flooding GitHub with hundreds of tiny task issues.

## Recommended GitHub Project fields
- Status: Todo / In Progress / In Review / Blocked / Done
- Phase: MVP / V1 / V2 / V3
- Priority: P0 / P1 / P2 / P3
- Epic: E01–E16


## Design-first gate

D0 Design Foundation is a prerequisite for full production implementation of the user-facing core loop. E01 may continue with non-UI foundation work in parallel, but product-facing contracts should not be considered stable until D0 interaction architecture is approved.
