# Accessibility & Design QA

## Required checks
- 44×44 minimum interactive target
- color contrast WCAG 2.2 AA
- semantic accessibility labels
- reading/focus order follows visual order
- text scales without clipping at large accessibility sizes
- reduced-motion mode
- dark/light compatibility where supported
- screen does not require color alone to identify status
- touch action has text equivalent
- error messages identify cause and recovery action
- location sharing state is always explicit
- destructive actions require confirmation
- challenge and competition language avoids humiliation/shame

## Prototype review checklist
- Movement loop has no dead ends.
- Crew-to-plan flow has no manual re-entry of known data.
- Challenge acceptance/counter is understandable.
- Ojoro Now can recover from “nothing exists.”
- Back navigation returns to the correct context.
- Primary action is visually dominant.
- Passive scrolling is never the only path forward.
