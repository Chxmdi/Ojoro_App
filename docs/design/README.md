# Superseded design documents

The documents in this folder describe the earlier D0 prototype built against
PRD v2.0 (in-memory data, its own palette scale and rounded corners). That
prototype has been removed from `apps/mobile`.

The source of truth for design is now `design-handoff/`:

- `design-handoff/prd/OJORO_PRD_v3.0.md` for behaviour and data
- `design-handoff/design-system/` (OJORO KINETIC) for visuals and components
- `design-handoff/SCREENS.md` and `design-handoff/screens/` for the 44 screens
- `design-handoff/HANDOFF.md` for build order and open decisions

Keep these files for history only. Don't build from them.
